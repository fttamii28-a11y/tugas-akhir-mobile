# Aplikasi Presensi Sekolah (Tugas Akhir Mobile)

Aplikasi penunjang produktivitas sekolah untuk mencatat kehadiran siswa secara online menggunakan Firebase[cite: 1].

## Fitur Utama:
- **Navigasi**: Memiliki 3 layar (Login, Dashboard, dan Input Data)[cite: 1].
- **Sensor/Hardware**: Menggunakan Kamera / GPS Lokasi[cite: 1].
- **Cloud/Backend**: Terhubung ke Firebase Realtime Database[cite: 1].

## Cara Menjalankan Proyek:
1. Unduh file `.aia` yang ada di repository ini.
2. Buka situs [MIT App Inventor](https://ai2.appinventor.mit.edu/).
3. Pilih menu *Projects* -> *Import project (.aia file from my computer)*.
